# 📚 Resources

This folder contains the learning resources I use during my journey toward becoming a Systems & AI Infrastructure Engineer.

> **Rule:** Resources are references, not achievements.  
> I will not try to finish everything. I will use resources to understand concepts and then build something.

# 🧭 How I Use Resources

For every major topic:

```text
Learn the concept
      ↓
Take short notes
      ↓
Solve problems or experiments
      ↓
Build something
      ↓
Document what I learned
```

I will avoid:

- ❌ Watching endless tutorials
- ❌ Collecting random courses
- ❌ Switching resources every week
- ❌ Copying projects without understanding

I will focus on:

- ✅ One good resource at a time
- ✅ Deep understanding
- ✅ Practice
- ✅ Building projects
- ✅ Documentation

## DSA Rule

Before checking a solution:

1. Understand the problem.
2. Think independently.
3. Try for 20–30 minutes.
4. Write the approach.
5. Implement it.
6. Review the solution only when genuinely stuck.
7. Re-solve the problem later.
