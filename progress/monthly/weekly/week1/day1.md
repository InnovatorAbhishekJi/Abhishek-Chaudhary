## Goal

Set up a Linux development environment using WSL and learn basic terminal navigation.

## Environment

* Windows 10
* WSL Version 2
* Ubuntu
* Linux User: abhishek

## Commands Practiced

### pwd

Shows the current working directory.

Example:

`/home/abhishek`

### ls

Lists files and directories.

### ls -la

Lists all files, including hidden files.

### mkdir

Creates a new directory.

Example:

`mkdir engineering-lab`

### cd

Changes the current directory.

### cd ..

Moves to the parent directory.

### cd ~

Moves directly to the user's home directory.

## Practice

Created a Linux workspace:

`/home/abhishek/engineering-lab`

Practiced moving between:

* Home directory
* Engineering lab directory
* Parent directory

## Important Learning
